          How to import it into Firefox

          1. Open Manage Bookmarks (Ctrl+Shift+O).
          2. Import and Backup › Restore › Choose File …
          3. Select the downloaded file and confirm.

          Restoring replaces all existing bookmarks with the contents of the file. That’s why the file also contains everything that wasn’t sorted. If you use Firefox Sync, the new structure will reach your other devices too.
